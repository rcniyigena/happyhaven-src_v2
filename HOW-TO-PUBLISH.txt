HOW TO PUT THIS WEBSITE ON GITHUB PAGES
=======================================

This folder contains the FINISHED website files (not source code).
GitHub Pages must serve THESE files, not your source code.

Option A - simplest (replace repo contents):
1. Go to your GitHub repo: rcniyigena/happyhaven-src
2. Delete the current contents (the source files) and upload EVERYTHING
   from this folder instead (index.html, assets, favicon.ico, robots.txt,
   .nojekyll - include hidden files!)
3. GitHub repo Settings -> Pages -> Source: "Deploy from a branch",
   Branch: main, folder: /(root). Click Save.
4. Wait 1-2 minutes, then open https://rcniyigena.github.io/happyhaven-src/

Option B - keep source and website in one repo (recommended):
1. In your repo, create a new branch named "gh-pages" containing ONLY
   these website files at its root.
2. Settings -> Pages -> Branch: gh-pages, folder: /(root). Save.
3. Open https://rcniyigena.github.io/happyhaven-src/

Option C - drag and drop (no git commands):
1. On your repo page: Settings -> Pages -> Branch: main /(root) -> Save.
2. Add file -> Upload files -> drag in all files from this folder ->
   Commit changes.
3. Open https://rcniyigena.github.io/happyhaven-src/

NOTE: When uploading, make sure the hidden file ".nojekyll" is included
(files starting with a dot are hidden - in Windows File Explorer enable
"Hidden items" to see it). Without it GitHub may block the assets folder.

NOTE: The photos load from the original happyhaven.info website, so they
appear only while that site stays online and you have internet access.

VIEWING ON YOUR OWN COMPUTER
----------------------------
Double-clicking index.html will not work (browsers block the scripts).
Open a terminal in this folder and run ONE of:
   npx serve .
   python -m http.server 8000
then open the address it prints (e.g. http://localhost:8000).
